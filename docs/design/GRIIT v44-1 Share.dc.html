173 Share sheet: swipe a style, pick a colour
Every share is an image the app renders, so it looks the same in Instagram, Messages and Photos. The preview fills the sheet; you swipe between the styles that fit the moment, and the dots count them. One colour row (Ink, Orange, White) applies to the current style. A caption is optional and travels as text, never as part of the image. Four targets: Instagram Story (primary), Save, Messages and More.

176 Which styles for which moment, and the 1080 spec
Which styles, for which moment
Photo proof
A Photo (default) · B Sticker · D Grid
Self-reported proof
C Card (default) · B Sticker · D Grid
Day secured
E Big number (default) · D Grid · B Sticker
Challenge finished
F Finish (default) · D Grid
Invite
G Invite only
Default colour
Ink. The last colour picked is remembered per style.
Spec at 1080 wide
Canvas
1080 × 1920 PNG, sRGB. B is RGBA with alpha 0 outside the block; all others are opaque.
Safe areas
Top 250 and bottom 340 hold nothing but background. Side margin 96. Content box 888 × 1330 at (96, 250).
Wordmark
"GRIIT" 40, weight 600, tracking 0.14em, at (96, 270). B puts it in the block, at 44.
Join line
"Join me · griit.app/invite/{code}" 30/38 500, last line of the content box. G: link plate 54/64. Uses inviteDeepLink(); no new domain.
Numbers
SF Pro Display Heavy 800, tabular, baked in. "Day {n}" 150 (A, C) or 170 (B, D) · "of {N}" 60–64 500 · E streak 520/470, −0.02em · F secured 200/190.
Type
Challenge label 36–40/44–48 500 caps 0.06em · task 56/66 (A) or 96/108 (C) 500 · user 36/44 500 · body 34–48.
A Photo
Photo cover-fit · bottom 1100 scrim (transparent → #0F0F0F at 85%) · plate radius 40, padding 48, in the colour · seal 72 (3px ring at 60%).
B Sticker
No plate. Colour = text: Ink #0F0F0F with a 18px glow at #F5F3EE 55% (for bright photos) · White #F5F3EE with an 18px shadow at #0F0F0F 60% (dark photos) · Orange #DC5401 with a shadow at 50%. Flame 64 brand. Seal 72 when camera.
C Card
Check disc 140 (Ink #3A1F10, Orange 12% ink, White #F8E3D5) + check 76 · "Self-reported" 38 500.
D / F grid
7 columns, cell 104, gap 14, radius 22. Secured: accent fill · held: sub at 60% · missed: 3px sub outline · today: 6px accent ring · future: line colour.
Palettes
Ink: bg #0F0F0F, fg #F5F3EE, sub #A39E95, accent #DC5401. Orange: bg #DC5401, fg #0F0F0F, sub #3A1405, accent #0F0F0F. White: bg #F5F3EE, fg #0F0F0F, sub #5E5A54, accent #DC5401.
Caption
Never baked into the image. It goes as text: Messages body, Instagram caption via the pasteboard, More → the share sheet text.
Render
Draw offscreen at 1080 × 1920 from the same component the preview uses (react-native-view-shot, result PNG), then hand that file to every target. The preview is that component scaled; never a separate layout.

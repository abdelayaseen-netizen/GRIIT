44 Home, today's proof card, six tasks and one
Six tasks is the real case. With more than one task the big button goes: there is no single next action, and a button naming one of six would be arbitrary, so the rows are the call to action. With exactly one task the button stays, because then it is not a guess. A pending row whose time window has closed goes inert and says so, with the window it missed.

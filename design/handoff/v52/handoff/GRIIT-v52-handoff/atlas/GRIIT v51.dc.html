Home rules · same family as the feed
Greeting
Title 1 (28) in Text 1, with the date under it. It is the screen title, like Discover and Activity, not a caption.
Streak card
The only card on Home: one unit (streak, week, today’s move). Unchanged from 2c apart from type.
Today
Flat rows on the ink ground, hairlines between, no container. Open tasks first; done tasks collapse into one “n done” row.
Checks
Open = outline circle. Done = the v48 done check (raised circle, check). No filled orange discs.
Tap
A row opens the task’s complete step. The card’s button runs the next open task; rows are for the rest.
Feed
Starts straight after the last hairline. The feed header and posts are the locked v50 style.

Viewer gestures
Swipe left / right
Next / previous task on the same day. The bars at the top show the day’s tasks.
Tap right / left edge
Next / previous photo inside a task (“1 of 2”), then the next task.

Previous day. Swipe up: next day. Opens at the first task.
Close

Newest day first, the same order as the grid. The last day shows “That’s the first proof.”
Private / shared

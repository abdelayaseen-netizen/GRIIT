Counter rules
Primary
“Complete · {target} {unit}” always, in any state. One tap sets the count to the target and saves.
Partial
“Log n of N” is a quiet text button under it; hidden at 0 and at the target.
Steppers
+1 / +5 / +10 cap at the target, then dim. “Type it” opens the number pad with Done bar (v48.1).
Camera gate
If the task also needs a photo, the primary reads “Complete · take photo” and opens the camera after setting the count.

Live Activity rules
Start
When a timer task starts. One activity per running timer.
Content
Task name, challenge · day, time left, progress. Dark ground; Text 1 and greys only.
Orange
Only the done check when time is up.
Pause
Freezes the countdown and shows “Paused · 12:41 left” with Resume.
Done
Ends the timer early and opens the save step; nothing saves from the Lock Screen.
Build
Widget extension + ActivityKit (iOS 16.2+), App Intents for buttons (iOS 17+). Below 17 the buttons open the app.
